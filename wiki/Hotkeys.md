# Hotkeys

One discrete key per action (no chords to collide with the game):

| Action | Default |
| ------ | ------- |
| Start Stream | F6 |
| Stop Stream | F7 |
| Start Record | F8 |
| Stop Record | F9 |
| Pause Record | F10 |
| Next Scene | F12 |
| Prev Scene | Insert |

F11 stays vanilla fullscreen, which is why scenes use F12/Insert.
Rebind everything in Setup → Keys: click a key, press the replacement
(Esc cancels). Bindings persist to `config/obsnomore.json`.
