# OBS No More — Wiki

In-game OBS Studio replacement for **every Legacy Fabric Minecraft version**:
stream to single or multiple RTMP servers and record with ffmpeg, with an
OBS-style scene editor and sources — no external OBS needed.

**Start here:** [Installation](Installation) → [Audio-Setup](Audio-Setup) →
[Video-Capture-Setup](Video-Capture-Setup) → [Streaming](Streaming)

## 30-second version

1. Install the mod jar + Java 17 + ffmpeg ([Installation](Installation)).
2. Open the game, press the OBS button (bottom-left) — the first-run
   wizard checks game capture and game audio actually work.
3. Add your stream key in Setup → Stream, press Start Stream.
